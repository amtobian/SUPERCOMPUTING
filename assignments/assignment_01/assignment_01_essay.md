 My understanding of why documented code is used to do computational research tasks is that someone else could reproduce those scripts and get the same results. Furthermore, if someone reproduces the raw data in a different run then they can use the same structure to analyze their results as well. Moreover, keeping comments in your code about what is happening helps others to follow your code, and helps you keep track of the changes that you are making. Comments also help you keep track of what changes you are making. Keeping track of what is happening is helpful so that if you take a break and then come back to the project, it is easy for you to remember where you were and what changes you were in the process of making. Keeping documented steps also helps you keep track of what software versions you are using. There are many reasons to use documented code, but the main reason is for reproducibility.
